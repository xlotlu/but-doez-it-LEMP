# User experience design

1 rotary encoder
1 button

switch between modes: lamp <-> tetris <-> paddle <-> light organ

when in lamp mode:
  - switch between colour channels  [button]
  - and tune the current channel    [rotenc]

when in tetris mode:
  - move piece left / right         [rotenc]
  - drop piece                      [button]

additional input methods:
- double click                      # accesibility grade: 3
- long press button                 # accesibility grade: 4
- press button & rotate encoder     # accesibility grade: 5
- double click and keep pressed     # accesibility grade: 2.8
